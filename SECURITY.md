# Security policy

## Supported versions

Security fixes are applied to the latest released version of LitheMark.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open
a public issue containing exploit details, sensitive local paths, or sample documents with
private information.

Include the LitheMark version, operating system, reproduction steps, expected behavior, and
the smallest safe test document that demonstrates the issue. Reports involving Markdown
sanitization, local resource boundaries, external URL handling, or unintended file writes
are treated as high priority.

LitheMark is a read-only local application. A report should not require uploading a user's
document to a third-party service.
